# Valet Cubed documentation

The source of [valetcubed.com](https://valetcubed.com), built with [Starlight](https://starlight.astro.build/).

```bash
npm install
npm run dev     # local preview at http://localhost:4321
npm run build   # static site in dist/
```

Pages are Markdown files in `src/content/docs/`. The sidebar is configured in `astro.config.mjs`.
