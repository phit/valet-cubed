Valet Cubed runs Nginx and PHP-FPM in the background and serves every project in your sites folder at `http://project-name.test`. It uses a few megabytes of RAM and gets out of your way.

It is a fork of [Valet Linux+](https://github.com/valet-linux-plus/valet-linux-plus), which forked [Valet Linux](https://github.com/cpriego/valet-linux), which forked [Laravel Valet](https://github.com/laravel/valet). Hence the name.

<CardGrid>
	<Card title="Park a folder, get sites" icon="rocket">

## Tested on

Every change runs through real installs on Ubuntu 24.04 and 26.04, Debian 13, Fedora 44, AlmaLinux 10, Arch Linux, openSUSE Leap 16.0 and ALT Linux p11.
